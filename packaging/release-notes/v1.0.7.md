## Cursor 额度圆环对齐 Codex

- 统一 Cursor 与 Codex 的额度圆环样式：圆角端点、彩色剩余弧在前。
- 修复剩余 100% 时圆环顶部仍留缺口的问题，现与 Codex 一样完整闭环。
- 侧边弹窗、首页额度卡片与 Cursor 详情页圆环表现一致。

## 下载与安装

- **macOS 14+ / Apple Silicon**：下载 `seeUtoken-V1.0.7.dmg`，打开后双击「安装 seeUtoken.pkg」；也可直接下载 `seeUtoken-V1.0.7.pkg`。
- **Windows 10/11 x64**：下载并运行 `seeUtoken-V1.0.7.exe`，按向导安装或覆盖升级。
- 三种安装文件均提供 `.sha256` 校验文件，升级保留个人设置与用量缓存。

macOS 应用使用 ad-hoc 签名，安装器尚未经过 Developer ID 签名及 Apple 公证；Windows 安装器也尚未做代码签名。Windows 需要 .NET Framework 4.8 与 Microsoft Edge WebView2 Runtime。
