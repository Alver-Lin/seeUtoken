## 安装与升级

- **macOS 14+ / Apple Silicon**：下载 `seeUtoken-V1.0.2.dmg`，打开后双击「安装 seeUtoken.pkg」；也可直接下载同名 `.pkg` 安装器。
- **Windows 10/11 x64**：下载并运行 `seeUtoken-V1.0.2.exe`，按安装向导完成安装。本版本 EXE 为正式安装器。
- 安装器会关闭已识别的旧版并覆盖固定位置的程序，保留个人设置和用量缓存；同版本重新安装也支持覆盖。
- macOS 固定安装到 `/Applications/seeUtoken.app`；Windows 默认安装到 `%LOCALAPPDATA%\Programs\seeUtoken\seeUtoken.exe`，复用开始菜单快捷方式与卸载记录。
- Windows v1.0.1 便携版用户安装后请使用开始菜单中的 seeUtoken。下载目录中的历史安装文件和自行保存的便携副本不会被自动删除。

## 校验与运行环境

安装包旁提供对应的 `.sha256` 校验文件。

Windows 需要 .NET Framework 4.8 与 Microsoft Edge WebView2 Runtime。macOS 应用目前使用 ad-hoc 签名，安装器尚未经过 Developer ID 签名及 Apple 公证；Windows 安装器也尚未做代码签名。请从本仓库 Releases 下载，并按系统提示操作。

macOS 与 Windows 已通过原生构建、覆盖升级、同版本重装和个人数据保留测试；Windows 另通过打包后 WebView2 启动检查。
