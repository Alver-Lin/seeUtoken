## macOS 旧版残留与重复图标修复

- 安装后清除 `/Applications` 和 `~/Applications` 中同一应用的旧版本副本。
- 在登录用户的会话中刷新应用注册，清理旧 DMG 挂载、废纸篓和临时打包路径留下的重复图标。
- 无人登录时，在新版本首次启动时补做清理。
- 打包完成后自动注销并回收临时 `.app`，防止项目构建目录产生额外应用图标。
- 保留个人设置、用量缓存、其他应用和下载目录中的安装文件。废纸篓中的文件遵循系统回收规则，清理其重复应用注册。

## 下载与安装

- **macOS 14+ / Apple Silicon**：下载 `seeUtoken-V1.0.3.dmg`，打开后双击「安装 seeUtoken.pkg」；也可直接下载 `.pkg` 安装器。
- **Windows 10/11 x64**：下载并运行 `seeUtoken-V1.0.3.exe`，继续使用固定安装目录覆盖升级。
- 三种安装文件均提供对应的 `.sha256` 校验文件。

macOS 应用目前使用 ad-hoc 签名，安装器尚未经过 Developer ID 签名及 Apple 公证；Windows 安装器也尚未做代码签名。Windows 需要 .NET Framework 4.8 与 Microsoft Edge WebView2 Runtime。
