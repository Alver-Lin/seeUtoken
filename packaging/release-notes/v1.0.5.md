## 额度圆环与侧边体验

- 统一 Cursor / Codex 额度圆环配色：剩余 90%–100% 绿色、50%–89% 蓝色、10%–49% 橙色、低于 10% 红色。
- 侧边弹窗百分比改为整数显示，避免出现长小数。
- 侧边弹窗圆环中心去掉「剩余」提示，仅在未登录或待更新时保留状态文案。
- Cursor 与 Codex 侧边进度色对齐为同一套剩余比例规则。

## 下载与安装

- **macOS 14+ / Apple Silicon**：下载 `seeUtoken-V1.0.5.dmg`，打开后双击「安装 seeUtoken.pkg」；也可直接下载 `seeUtoken-V1.0.5.pkg`。
- **Windows 10/11 x64**：下载并运行 `seeUtoken-V1.0.5.exe`，按向导安装或覆盖升级。
- 三种安装文件均提供 `.sha256` 校验文件，升级保留个人设置与用量缓存。

macOS 应用使用 ad-hoc 签名，安装器尚未经过 Developer ID 签名及 Apple 公证；Windows 安装器也尚未做代码签名。Windows 需要 .NET Framework 4.8 与 Microsoft Edge WebView2 Runtime。
