## 跨工具汇总记录

- 新增「汇总记录」模块，集中展示 Cursor 与 Codex 的模型 Token 用量、使用记录、年度热力图及近 90 日趋势。
- 同名模型合并统计并标注工具来源，支持今日、本周、本月与全部时段，沿用统一的缓存统计设置。
- Token 合计显示完整整数；使用记录按时间倒序分页，保留工具、模型、项目、提问与 Token 拆分。
- Cursor 通过完整分页用量明细补齐真实调用次数，并核对接口报告的总条数，避免以近期记录数代替总量。

## 用量与桌面体验

- 首页额度卡片新增近 7 日用量柱状图；侧边栏用量数字与展开动画保持一致。
- Codex 详情新增剩余重置卡数量展示，未知时保留获取状态。
- 统一 Cursor 与 Codex 使用记录的 Token 布局；Codex 不展示缺少数据的计费类型列。
- 调整顶部导航的选中配色与玻璃外观，将汇总刷新操作收为顶部图标按钮。
- 改进 Windows 贴边自动收起、悬停展开与窗口显示行为，并修正额度缺失、登录失效时的展示。

## 下载与安装

- **macOS 14+ / Apple Silicon**：下载 `seeUtoken-V1.0.4.dmg`，打开后双击「安装 seeUtoken.pkg」；也可直接下载 `seeUtoken-V1.0.4.pkg`。
- **Windows 10/11 x64**：下载并运行 `seeUtoken-V1.0.4.exe`，按向导安装或覆盖升级。
- 三种安装文件均提供 `.sha256` 校验文件，升级保留个人设置与用量缓存。

Cursor 的「全部」覆盖本年度可读取的云端记录；Codex 统计当前设备保留的本机会话。Qoder 尚未接入真实用量数据。

macOS 应用使用 ad-hoc 签名，安装器尚未经过 Developer ID 签名及 Apple 公证；Windows 安装器也尚未做代码签名。Windows 需要 .NET Framework 4.8 与 Microsoft Edge WebView2 Runtime。
