## Cursor 用量与会话匹配

- 修复新版 Agent 会话「会话内容」为空的问题：headers 为空时回退读取本机 user bubble。
- 修复「全部」时段模型 Token 偶发空白：聚合接口缺模型行时，用完整调用明细回填。
- 汇总记录中 Cursor 模型用量更稳定，刷新时不再用空的「全部」数据覆盖已有结果。
- 侧边弹窗与首页额度卡片圆环百分比下方恢复「剩余」提示。

## 下载与安装

- **macOS 14+ / Apple Silicon**：下载 `seeUtoken-V1.0.6.dmg`，打开后双击「安装 seeUtoken.pkg」；也可直接下载 `seeUtoken-V1.0.6.pkg`。
- **Windows 10/11 x64**：下载并运行 `seeUtoken-V1.0.6.exe`，按向导安装或覆盖升级。
- 三种安装文件均提供 `.sha256` 校验文件，升级保留个人设置与用量缓存。

macOS 应用使用 ad-hoc 签名，安装器尚未经过 Developer ID 签名及 Apple 公证；Windows 安装器也尚未做代码签名。Windows 需要 .NET Framework 4.8 与 Microsoft Edge WebView2 Runtime。
